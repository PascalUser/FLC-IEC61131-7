## Key Semantic Actions

Excerpt from `src/main/java/parser/Parser.y`:

| Rule                              | Semantic Action                                                                                                                                  |
|-----------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------|
| `function_block_name`             | Creates `ParsingContext`, adds the name to `outerScopes`, `contexts.add(ctx)`                                                                    |
| `function_block_declaration`      | Upon reducing `END_FUNCTION_BLOCK`: `contexts.pop()`                                                                                             |
| `io_var_decl` (VAR_INPUT)         | `ctx.metadataBuilder().source(Source.IN).use(Use.VARIABLE)`                                                                                      |
| `io_var_decl` (VAR_OUTPUT)        | `ctx.metadataBuilder().source(Source.OUT).use(Use.VARIABLE)`                                                                                     |
| `var_id_decl` (VAR)               | `ctx.metadataBuilder().source(Source.INTERNAL).use(Use.VARIABLE)`                                                                                |
| `var_init_decl`                   | `contexts.publish(); ctx.declaredIdentifiers().clear()`                                                                                          |
| `custom_type_name`                | Looks up `LexemeInfo`, sets `type=SIMPLE, subtype=CUSTOM`, and adds the underlying scope to `searchScope`                                        |
| `custom_specification`            | Sets `type=SIMPLE, subtype=CUSTOM, customType=$1`, fetching `initialValue` from `SymbolTable`                                                    |
| `simple_specification`            | `type=SIMPLE, subtype=$1, initialValue=Factory.createPrimitiveInitialization(...)`                                                               |
| `range`                           | Accumulates bounds in the builder's `inferiorLimits` / `superiorLimits`                                                                          |
| `enumerated_values_list`          | Creates child context per enum value, sets `use=MACRO, source=NONE`, publishes each literal                                                      |
| `array_specification`             | `type=ARRAY, initialValue=RepeatedInitialization(dimension, defaultInit)` for custom or primitive element                                        |
| `array_initial_elements`          | Consolidates intervals using `RepeatedInitialization.addInterval(start, end, init)` and resets the index                                         |
| `structure_field_declaration`     | New context per field, `use=FIELD, source=NONE`, publishes and `pop`s upon reduction                                                             |
| `structure_specification`         | `type=STRUCT, subtype=NONE, parameters=fields`; constructs `parser.initializations.nodes.StructInitialization` with the `initialValue` per field |
| `type_string_specification`       | Sets `subtype=STRING` or `subtype=WSTRING` in the builder                                                                                        |
| `string_specification`            | `type=SIMPLE`, `initialValue=Factory.createPrimitiveInitialization(symbolTable, subtype)`                                                        |
| `string_specification` with `[n]` | Same as above, but additionally sets `superiorLimits=[n]` with the declared length                                                               |
| `initialized_string`              | `initialValue=new VariableInitialization($3)` parsed from `string_constant`                                                                      |
| `type_declaration`                | `outerScopes.popScope(); contexts.publish(); declaredIdentifiers().clear()`                                                                      |

Notes:

* `Factory.createPrimitiveInitialization` (in `parser.initializations`) delegates to `DefaultInitialization` (in `parser.initializations.leafs`), which supports **all** primitive subtypes: BOOL, STRING, WSTRING, REAL/LREAL, and all integers (SINT..ULINT). Throws an `IllegalArgumentException` for unsupported subtypes.
* The classes `StringInitialization`, `WStringInitialization`, `IntInitialization`, `BooleanInitialization`, `RealInitialization`, and `AbstractPrimitiveInitialization` **have been removed**; their roles are entirely fulfilled by `DefaultInitialization`.
* The publication to the `SymbolTable` is handled by `ContextHandler.publish()`, rather than a separate `Publisher` class.

Default behavior of `variableValue`:

| Class                           | Default Value                         | `SymbolTable` Registration                      |
|---------------------------------|---------------------------------------|-------------------------------------------------|
| `VariableInitialization`        | assigned literal or identifier        | does not register (wrapper only)                |
| `DefaultInitialization` BOOL    | `FALSE`                               | `putIfAbsent` via `Director.makeDefaultBoolean` |
| `DefaultInitialization` REAL    | `0.0`                                 | `putIfAbsent` via `Director.makeDefaultReal`    |
| `DefaultInitialization` INT     | `0`                                   | `putIfAbsent` via `Director.makeDefaultInteger` |
| `DefaultInitialization` STRING  | `''`                                  | `putIfAbsent` via `Director.makeDefaultString`  |
| `DefaultInitialization` WSTRING | `""`                                  | `putIfAbsent` via `Director.makeDefaultWString` |
| `EnumeratedInitialization`      | first enum value                      | does not register (selects the value)           |
| `MacroInitialization`           | ordinal of the enum literal           | `putIfAbsent` with `subtype=INT`                |
| `SubrangeInitialization`        | lower bound                           | does not register                               |
| `StructInitialization`          | map: field → `Initialization`         | does not register                               |
| `RepeatedInitialization`        | partition of intervals `[start, end]` | does not register                               |

All lazy default values use a `static DEFAULT` field (in `Director`) and `SymbolTable.putIfAbsent`, ensuring the same table doesn't duplicate a literal's entry.
