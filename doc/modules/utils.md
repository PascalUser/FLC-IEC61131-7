## Class Table

| Class                              | Responsibility                                                                                                                  | Pattern             |
|------------------------------------|---------------------------------------------------------------------------------------------------------------------------------|---------------------|
| `utils.SymbolTable`                | Stores and retrieves `LexemeInfo` by lexeme name                                                                                | Repository          |
| `utils.LexemeInfo`                 | DTO with complete semantic attributes (type, subtype, use, source, limits, parameters, initial value)                           | Value Object        |
| `utils.DiagnosticsHandler`         | Collects and manages diagnostics (errors/warnings) in insertion order                                                           | Collector           |
| `utils.builders.LexemeInfoMutator`  | Fluent contract with a setter per `LexemeInfo` attribute (does not declare `build()`)                                           | Builder (interface) |

| `utils.builders.Director`          | Static recipes: `makeLiteral`, `makeType`, `makeMacro`, `makeDefaultInteger` and default values REAL, BOOL, STRING, and WSTRING | Director            |
| `utils.enums.Type`                 | General classification: UNKNOWN, SIMPLE, ENUMERATE, SUBRANGE, ARRAY, STRUCT                                                     | Enum                |
| `utils.enums.Subtype`              | IEC 61131-7 primitive types (INT, REAL, BOOL, TIME, etc.) + CUSTOM/NONE                                                         | Enum                |
| `utils.enums.Use`                  | Usage context: VARIABLE, FIELD, LITERAL, FUNCTION, RULE, TYPE, MACRO, OPTION, UNKNOWN                                           | Enum                |
| `utils.enums.Source`               | Declaration block: IN, OUT, INTERNAL, FUZZIFY, DEFUZZIFY, NONE, UNKNOWN                                                         | Enum                |

## How to test

Unit tests in `src/test/java/unit/utils/SymbolTableTest.java` (`SymbolTable` is the only `utils` type with its own unit test):

* `PutAndGet_StoresAndRetrievesLexemeInfo` — verifies basic `put`/`get`
* `Put_WithVariousLexemeInfo_StoresCorrectly` — parameterized with 5 combinations of Type/Subtype/Use/Source
* `Get_ForNonExistentKey_ReturnsNull` — behavior for a non-existent key
* `Put_OverwritesExistingKey_ReturnsOldValue` — overwrites and returns the previous value
* `PutIfAbsent_Behavior` — 3 cases: absent key, existing key (does not overwrite), existing key with a different value
* `PutIfAbsent_NullValue_StoresNull` — allows null values
* `Size_ReturnsEntryCount` — size with 0, 1, and 2 initial entries
* `Size_AfterPutIfAbsent_IncrementsOnlyForNewKeys` — size increments only for new insertions

Execution:

```bash
mvn test -Dtest=SymbolTableTest

```

## Other `utils` packages in the project

In addition to the main `utils` package, there are three auxiliary packages with specialized utilities:

### `parser.utils`

| Class                      | Responsibility                                                                            | Pattern                 |
|----------------------------|-------------------------------------------------------------------------------------------|-------------------------|
| `parser.utils.NameMangler` | Generates qualified (mangled) names for symbols in nested scopes using `#` as a separator | Utility / Scope Manager |

**`NameMangler`** — Manages the scope stack to generate global unique keys in IEC 61131-7 (which uses a flat namespace but supports nested structures):

* `addScope(scope)` — Pushes a new scope onto the stack
* `getCurrentScope()` — Current full prefix without the trailing `#`
* `popScope()` — Pops and returns the last scope
* `getNameMangled(name)` — Returns the fully mangled name (e.g., `TYPE#FIELD#VALUE`)

### `lexer.semantics.utils`

| Class                                 | Responsibility                                                    | Pattern                 |
|---------------------------------------|-------------------------------------------------------------------|-------------------------|
| `lexer.semantics.utils.ReservedWords` | Lookup table for IEC 61131-7 reserved words → lexer token numbers | Registry / Lookup Table |

**`ReservedWords`** — Static `String → Integer` map with ~80 entries covering:

* Boolean literals (`TRUE`, `FALSE`)
* Program blocks (`FUNCTION_BLOCK`, `FUZZIFY`, `DEFUZZIFY`, `RULEBLOCK`, `OPTION`)
* Control structures (`IF`, `THEN`, `RULE`, `WITH`, `ACT`, `ACCU`)
* Fuzzy operators (`COG`, `COGS`, `COA`, `LM`, `RM`, `NC`, `MIN`, `MAX`, `ASUM`, `BSUM`, `PROD`, `BDIF`, `NSUM`)
* Variable declarations (`VAR_INPUT`, `VAR_OUTPUT`, `VAR`, `END_VAR`, `RETAIN`, `NON_RETAIN`, `CONSTANT`)
* Data types (`BOOL`, `SINT`, `INT`, `DINT`, `LINT`, `USINT`, `UINT`, `UDINT`, `ULINT`, `REAL`, `LREAL`, `STRING`, `WSTRING`, `BYTE`, `WORD`, `DWORD`, `LWORD`, `TIME`, `DATE`, `DATE_AND_TIME`, `ARRAY`, `OF`, `STRUCT`, `END_STRUCT`, `TYPE`, `END_TYPE`)
* Method: `isReserved(identifier)` → `tokenNumber` or `null`

### `lexer.transformers.utils`

| Class                                     | Responsibility                                            | Pattern                 |
|-------------------------------------------|-----------------------------------------------------------|-------------------------|
| `lexer.transformers.utils.ExponentFinder` | Locates the exponent character (`E`/`e`) in real literals | Utility / String Parser |

**`ExponentFinder`** — Static `find(lexeme)` method that returns the index of the first occurrence of `E` or `e` (uppercase has priority if both exist), or `-1` if there is no exponent. Used by the lexer to parse IEC 61131-7 scientific notation (e.g., `1.5E10`, `3.14e-5`).
