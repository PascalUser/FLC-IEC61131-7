WHY THIS PATCH BUNDLE EXISTS
The user asked for documentation to reflect the current implementation, not
historical package names. They also asked to consolidate meaningless
single-category/single-bar charts, explain Repository and lowering placement,
justify simulation and its validity, update production and test Javadocs, and
leave a durable log for future agents.

PATCHES IN THIS BUNDLE

  Adds doc/ARCHITECTURE.md and doc/SIMULATION.md, plus links from README.

  Adds package-info.java documentation for compiler, lexer, parser and

JAVADOC QUALITY RULE
Documentation must match the current implementation. A Javadoc comment that
names an old package, claims immutability where fields are mutable, or describes
a former pipeline is worse than no comment. Avoid blanket statements such as
"all public methods documented" until an audit verifies that claim.

SIMULATION CLAIMS TO PRESERVE
The current test harness compares ReferenceSimulator and QuantizedSimulator
over a finite input grid. step=1 enumerates the model's representable input
combinations; larger steps sample. It covers MIN-MAX and centroid of
singletons only. It does not execute generated C++, synthesize hardware, prove
formal equivalence, or establish full IEC 61131-7 compliance.
